# Design System

> **Status: PLACEHOLDER — Phase 2 document.** Visual design and
> prototyping decisions are deliberately NOT made in Phase 1.

To be defined during Phase 2 together with the product owner (creative
director):

- Brand name, logo and visual identity
- Typography, color, spacing and motion language
- Data-visualization grammar for narratives, analytics and conditional
  predictions
- Component inventory and interactive prototypes (working files in
  `docs/design/`)
- Accessibility and responsive targets
