## Working description (from project brief, 2026-11-26)

FinStory is a consumer-oriented financial storytelling platform that
transforms human-authored editorial content into visually compelling
narratives, macroeconomic insights, quantitative analytics and conditional
market predictions.

Context recorded in Phase 1:

- Final commercial name and branding are undecided.
- The product owner acts as creative director; editorial content is
  human-authored.
- An LLM (Qwen via Arli AI) supports content transformation. Assume
  limited context capacity and single-request concurrency (see D-006 in
  `docs/DECISIONS.md`).

## To be defined in Phase 2

- Editorial pipeline: input format → transformed outputs
- Feature scope and prioritization (narratives, insights, analytics,
