# Source Material

Human-authored editorial source content for FinStory (articles, research
notes, data references) that the platform transforms into narratives and
analytics.

Conventions:

- One file or folder per editorial piece.
- Keep original, unmodified inputs here; derived/transformed output
  belongs elsewhere (to be defined in Phase 2).
- Never store credentials or third-party personal data here.

*(Phase 1: empty by design — content arrives with Phase 2 product work.)*
